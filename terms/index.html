Propriété intellectuelle

Flucilien est un projet étudiant de datavisualisation réalisé dans le cadre du BUT MMI par Léo Lesimple (conception graphique, front-end) et Tom Delavigne (back-end, traitement des données). Le code est publié sous licence GNU AGPL v3. La charte graphique est dérivée de celle d'Île-de-France Mobilités (2022). Les données de validation et d'incidents proviennent de l'open data d'Île-de-France Mobilités et de la SNCF. Les crédits des images figurent sur la page Crédits.

Polices : Fira Sans, Fira Sans Condensed et Space Grotesk, sous licence SIL Open Font License 1.1, hébergées avec le site. Bibliothèques : Chart.js (licence MIT) et MapLibre GL JS (licence BSD), hébergées avec le site.
